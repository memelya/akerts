## Запуск на ноутбуке

1. Скачайте и полностью распакуйте архив.
2. Запустите `START_LOCAL.cmd`. Нужен установленный Python 3.10 или новее.
3. Оставьте окно сервера открытым. Браузер откроется автоматически.
4. Замените `date/push-sms.csv` и `date/success-screen.csv` своими выгрузками.
5. Нажмите «Обновить данные» или F5.

Альтернативный запуск: `python start_local.py`; на macOS/Linux — `python3 start_local.py`.
Для обновления CSV нужен именно этот сервер. Команда `python -m http.server` показывает статическую копию.
Node.js, npm, интернет и внешние сервисы для локальной работы не требуются.

## Форматы CSV

Пуш и СМС:

```csv
day_part;event_type_id;status_det;answer_csi;events;sends;answers
```

Экраны успеха:

```csv
day_part;event_type_id;mp_status;answer_csi;sends;answers
```

Для ЭУ `sends` — количество записей статуса с данной оценкой. На графике события суммируют эти количества по всем статусам; «Отправки · SENDED» учитывают только SENDED; ответы суммируются по `answers`. CSI взвешивается по количеству записей с оценками 1–5. Пустые оценки не входят в CSI.

Также поддерживается прежний агрегированный формат ЭУ: `month,event_type_id,mp_status,cnt,qa_cnt,csi`.
Разделители: точка с запятой, запятая, табуляция. Кодировки: UTF-8, UTF-16, Windows-1251.

## История и замена

Повтор ключа заменяется последней строкой, без суммирования. Дневной ключ включает дату, ID, статус и оценку.
Новые даты, месяцы и опросы добавляются автоматически. Принятая история хранится локально в `.local-data/updates.json`.
При переносе проекта сохраняйте свои папки `date` и `.local-data`.
CSV с ошибкой не применяется; на странице показываются файл и строка ошибки, а последние корректные данные сохраняются.

Подробная инструкция входит в архив: `README.html` и `README.txt`.
