# Дашборд статусов событий

Статический HTML-дашборд по агрегированным данным `month + event_type_id + status_det`.

- `dist/index.html` — общая страница с поиском и сортировкой.
- `dist/events/<event_type_id>.html` — отдельная страница каждого события.
- `data/source.tsv` — очищенные строки источника (без демонстрационного примера).
- `data/events.json` — нормализованный набор данных.

Главная страница по умолчанию показывает зафиксированный список топ-опросов; переключатель открывает полный каталог. Для приоритетных ID, отсутствующих в выборке, созданы отдельные страницы с явным состоянием «нет данных».

Все графики строятся локально на SVG, внешние библиотеки и подключение к интернету не нужны. Отсутствующие сочетания «месяц + статус» отображаются как ноль.

На странице каждого опроса есть панель алертов. Она накапливает изменения общего объёма и отдельных статусов больше 10% месяц к месяцу, показывает сначала новые записи и разделяет рост и снижение. Переходы от нулевого значения не считаются процентным алертом, поскольку для них нет корректной базы сравнения.

Сравнение сентября с октябрём 2026 года временно отключено во всех процентах и алертах, потому что октябрь представлен неполным месяцем. Сами октябрьские объёмы и точки на графиках сохраняются.

## Пересборка

```powershell
node scripts/generate-site.mjs "ПУТЬ_К_ФАЙЛУ_С_ИСХОДНЫМ_ТЕКСТОМ"
```
