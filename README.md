# Дашборд статусов событий

Статический HTML-дашборд по агрегированным данным `month + event_type_id + status_det`.

- `dist/index.html` — общая страница с поиском и сортировкой.
- `dist/events/<event_type_id>.html` — отдельная страница каждого события.
- `data/source.tsv` — очищенные строки источника (без демонстрационного примера).
- `data/events.json` — нормализованный набор данных.
- `data/success-screen.csv` — отдельный источник канала «ЭУ — экран успеха» со статусами `mp_status`; исходные CSI сохранены без преобразования.

Для #3434, #3202, #1598, #480, #154 и #155 события ЭУ суммируются по `cnt` всех `mp_status` и входят в общие итоги платформы и соответствующей группы опросов. Ответы ЭУ — сумма `qa_cnt` всех статусов, без предположения об уникальности клиентов. Данные помечены `channel: success_screen` и `statusModel: mp_status` в `data/events.json`. На детальной странице показаны три графика: все события, ответы и CSI. Регистр статусов сохраняется: `CLOSE_WIDGET` и `close_widget` у #1598 учитываются как отдельные строки исходной выгрузки. Модель отправок `status_det = 0`, рекомендации по темпу и её правила отклонений к ЭУ не применяются. Одновременная загрузка одного ID в двух статусных моделях отклоняется, чтобы не смешивать каналы неявно.

CSI ЭУ рассчитывается помесячно по запрошенным атрибутам `cnt` и `csi`: `sum(cnt * csi) / sum(cnt)`. В обоих суммах участвуют только строки с `cnt > 0` и CSI в диапазоне 1–5. Нулевые CSI остаются в исходных данных, но означают отсутствие оценки и не снижают среднее. Веса — `cnt`, не `qa_cnt`. Месячные CSI и сумма допустимых весов сохраняются как `csiValues` и `csiWeights`; промежуточного округления нет. CSI также отображается в карточке и таблице сравнения.

По этой же схеме добавлены ЭУ #746, #1593, #1595, #1597 и #2825. Если в месяце нет допустимых CSI, сохраняется `null`: график оставляет разрыв, а таблица и актуальное значение показывают «—». Например, в октябре 2026 у #1597 нет оценок; события и нулевое число ответов при этом сохраняются. Месяцы не заполняются предыдущей оценкой и не превращаются в нулевой CSI.

Главная страница по умолчанию показывает зафиксированный список топ-опросов; переключатель открывает полный каталог. Для приоритетных ID, отсутствующих в выборке, созданы отдельные страницы с явным состоянием «нет данных».

Все графики строятся локально на SVG, внешние библиотеки и подключение к интернету не нужны. Отсутствующие сочетания «месяц + статус» отображаются как ноль.

На странице каждого опроса есть панель алертов. Она накапливает изменения общего объёма и отдельных статусов больше 10% месяц к месяцу, показывает сначала новые записи и разделяет рост и снижение. Переходы от нулевого значения не считаются процентным алертом, поскольку для них нет корректной базы сравнения.

Сравнение сентября с октябрём 2026 года временно отключено во всех процентах и алертах, потому что октябрь представлен неполным месяцем. Сами октябрьские объёмы и точки на графиках сохраняются.
