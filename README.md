# Дашборд статусов событий

Статический HTML-дашборд по агрегированным данным `month + event_type_id + status_det`.

- `dist/index.html` — общая страница с поиском и сортировкой.
- `dist/events/<event_type_id>.html` — отдельная страница каждого события.
- `data/source.tsv` — очищенные строки источника (без демонстрационного примера).
- `data/events.json` — нормализованный набор данных.

Все графики строятся локально на SVG, внешние библиотеки и подключение к интернету не нужны. Отсутствующие сочетания «месяц + статус» отображаются как ноль.

## Пересборка

```powershell
node scripts/generate-site.mjs "ПУТЬ_К_ФАЙЛУ_С_ИСХОДНЫМ_ТЕКСТОМ"
```
