НОВЫЕ ВИЗУАЛИЗАЦИИ · 2026.11.02.1

КАК ПОПРОБОВАТЬ
1. Подключите GigaCode через START_GIGACODE.cmd. Загрузите свои CSV в date.
2. В диалоге включите «Создать новую визуализацию». Это отдельный режим;
   обычные графики и AI мониторинг продолжают работать как раньше.
3. Опишите задачу, а не обязательно тип графика. Например:
   «Создай новую визуализацию продукта Вклады за последние семь дней:
    сравни CSI и выполнение плана ответов, дай выбор опроса нажатием».
   «Создай новый интерфейс: доли отправок каждого опроса продукта Вклады
    по месяцам за 2026 год. Помоги увидеть, кто изменил общую картину».
   Явные просьбы создать новый интерфейс также распознаются без флажка.
4. Модель сначала выбирает данные; сервер рассчитывает их локально.
   Затем модель пишет HTML, CSS и JavaScript нового компонента.
5. Сначала появится подтверждение состава расчёта: продукт, период,
   показатели, приоритет, канал, число опросов. Период без явного запроса —
   последний загруженный месяц продукта. Старый ID другого графика
   не ограничивает явно названный продукт. «Изменить запрос» возвращает
   условия в диалог; «Создать интерфейс» запускает генерацию кода.
   После этого откроется ЧЕРНОВИК. Он ещё не меняет текущий результат.
   Проверьте шкалы, единицы, пропуски, подписи и кнопки. Ниже доступны:
   объяснение выбора интерфейса, независимая таблица расчётов, исходный код.
6. «Применить визуализацию» добавляет новый результат или обновляет текущий
   в соответствии с флажком контекста. «Отклонить» сохраняет старый экран.
   «Уточнить задачу» переносит ваше уточнение в диалог: отправьте его,
   чтобы модель создала следующий вариант. «Посмотреть текущий экран»
   временно скрывает черновик; кнопка возврата сохраняет его для проверки.
7. При ошибке предпросмотр останавливается. «Исправить через модель»
   отправляет ошибку и тот же снимок данных отдельным явным вызовом.
   Не больше пяти модельных вызовов на генерацию, включая исправления.
   Ошибка типов в плане автоматически возвращается модели на исправление
   один раз. Число 30 не превращается в фильтр приоритета или обрезку отбора.

ЧТО ОТЛИЧАЕТСЯ ОТ ГОТОВЫХ БЛОКОВ
Новый код не выбирает компонент из существующего списка графиков сайта.
Модель может создавать свою HTML/SVG структуру, компоновку, оформление,
расчёт координат и взаимодействия. Внешние библиотеки, React, Canvas DOM,
произвольные обращения к API и загрузки ресурсов в первой версии запрещены.
Доступен ограниченный интерфейс ui.render / ui.onAction / ui.select,
а также замороженные данные ui.data / ui.facts и размер ui.viewport.
Это позволяет делать новые карты, матрицы, списки, диаграммы и переключения,
сохраняя границы доступа и понятный пользователю процесс применения.

КОНТРОЛЬ ДАННЫХ
Модель получает компактный портрет данных: схему, диапазоны, число
опросов, пропуски и до пяти помеченных примеров для проектирования.
Полный набор рассчитанных значений остаётся в браузере и сохранённом
компоненте. Примеры не ограничивают состав расчёта или визуализации.
Названия опросов, продуктов и версия источника входят в контекст. Исходные CSV строки не передаются. GigaCode использует своего
настроенного провайдера модели и свою авторизацию.

Поддерживаются отправки, ответы, события, CSI, отсечения стоп листов,
политики контактов, план ответов окна, выполнение плана и отношение ответов
к отправкам периода. Последнее не является когортной конверсией клиентов.
CSI взвешен по events; оценка ноль не входит в CSI, но ответы сохраняются.
План распределён равномерно по календарным дням окна. Неизвестный план
остаётся неизвестным. Выполнение = ответы / известный план окна × 100.
Доли вычисляются среди опросов отбора для соответствующего показателя
и периода; при неизвестном значении хотя бы одного участника доля не задана.
Доля для CSI и процентных показателей не рассчитывается.

Ссылки F... связывают видимые значения с локальными расчётами. Система
проверяет существование ссылок и подставляет эти подписи из источника.
Она НЕ доказывает корректность геометрии, выбора осей, визуальных акцентов
или произвольных подписей, написанных моделью. Сопоставляйте график
с независимой таблицей. Предпросмотр не является подтверждённым анализом.
При слишком мелких SVG подписях появится замечание и возможность исправить.

ИЗОЛЯЦИЯ
Компонент отображается в iframe без same origin, доступа к основному
документу, локальным файлам, формам, всплывающим окнам и внешней сети.
HTML/SVG очищается по списку тегов и атрибутов; script, iframe, foreignObject,
изображения и обработчики on... не принимаются. CSS ресурсы запрещены.
Сгенерированный JavaScript работает в отдельном Worker без DOM. Он может
только отправить новую разметку или предложить выбор известного опроса.
Выбор не запускает внешний запрос автоматически: пользователь сам нажимает
«Открыть обычный график». Код с ошибкой или зависанием останавливается.
Это изоляция браузера, а не формальная гарантия от всех ошибок произвольного
кода или чрезмерного потребления памяти. Используйте современный браузер.

БИБЛИОТЕКА И ВОЗВРАТ
После применения можно сохранить компонент в «Библиотеку визуализаций».
Сохраняются код и снимок рассчитанных данных в .local-data/generated-ui.sqlite3.
Они переживают F5 и перезапуск сервера. Можно открыть или удалить запись.
Новые CSV НЕ меняют сохранённый снимок автоматически. Для новых данных
откройте вариант и нажмите «Изменить этот интерфейс», уточните запрос.
Библиотека доступна в боковом меню.
Предыдущий шаг диалога можно вернуть обычной кнопкой возврата; история
диалога по прежнему хранится в текущей вкладке. Экспорт компонента JSON
содержит его код И рассчитанные данные — учитывайте это при передаче файла.
Сохранённые пользовательские компоненты и данные не входят в GitHub архив.

ПРЕДЕЛЫ ПЕРВОЙ ВЕРСИИ
До пятисот опросов, от одного до четырёх показателей, до 18000 временных
значений. Полный набор для браузера ограничен четырьмя миллионами символов.
Лимит в 9000 символов для полного набора удалён; компактный портрет
для модели обычно укладывается в 7000 символов. При превышении
попросите меньший период или более узкий отбор: скрытого усечения нет.
До 10000 символов суммарного кода, до 3000 элементов в одной отрисовке.
Библиотека содержит до двадцати снимков. Предпросмотру нужен первый вывод
с привязанным видимым значением; бесконечный цикл прекращается отдельно.
Черновики хранятся среди последних восьми модельных заданий в памяти.
PNG и редактор привычных графиков доступны через обычную детализацию;
экспорт PNG произвольного нового компонента в этой версии не добавлен.

ПРОВЕРЕНО
Процессные вызовы тестовой CLI, связность данных, согласованное применение,
отклонение, уточнение, библиотека после перезапуска, ошибка и исправление,
остановка бесконечного цикла, блокировка внешних ресурсов и попыток выхода
из iframe проверяются автоматически. Реальная GigaCode и качество её
визуальных решений требуют проверки с авторизацией на вашем ноутбуке.

ЛОГ ЭТАПОВ
«Ответ CLI получен» подтверждает только получение ответа, а не готовый
график. Отдельные записи показывают проверку/отклонение плана, исправление
параметров, подготовку полного набора, ожидание подтверждения, создание
черновика, проверку предпросмотра и применение пользователем.
При ограничении ресурса вместо бесполезного повторения предлагаются
обзор без временных рядов, последний загруженный месяц или изменение
условий. Любое изменение выполняется только по выбранному действию.


ДНЕВНОЙ ПЛАН И ПРОСМОТР РАСЧЁТА
Запрос «Покажи отклонения от планового количества ответов 2000 в день по опросу 1007»
фиксирует пользовательский план на календарный день для этого запроса.
Число 2000 не является ID и не заменяет справочник. Отдельно считаются факт,
план и отклонение факт минус план. Пропуски не равны нулю, итоговое отклонение
неполного окна неизвестно. План месяца равен дневному плану × число дней окна.
Явный номер опроса заменяет номер предыдущего графика; период можно сохранить
из контекста или указать заново. Без периода и контекста берутся последние 7 дней
от последней дневной строки выбранного опроса.
Явные условия разбираются локально, без вызова модели. В окне подтверждения
есть кнопка «Показать расчёт без генерации». Стандартный просмотр содержит
график факта и плана и таблицу отклонений. Он доступен без настроенной CLI.
Создание нового оформления запускается отдельно после подтверждения и требует CLI.
Для сравнения с дневным планом используется сокращённая инструкция генерации;
не создаётся большой универсальный редактор. Время ответа модели не гарантируется.
Кнопка просмотра расчёта доступна при ожидании кода и после ошибки/таймаута.
Она открывает сохранённый расчёт и не подменяет ответ модели готовым шаблоном.
