СПРАВОЧНИК ПРОДУКТОВ
Файл: date/products.csv. Колонки: Опрос;Продукт
Пример:
514;Вклады
1007;Общебанк
35;ЕСЗК_Развитие сервиса
3434;ЕСЗК_Развитие сервиса

Повторяющиеся связи учитываются один раз. Пустой продукт и отсутствие
опроса в справочнике означают «без продукта». Если у номера несколько
разных продуктов, он входит в каждый из них один раз.
Сохраните CSV и нажмите «Проверить данные» либо отправьте запрос.
Справочник перечитывается целиком, включая удалённые связи.

Примеры запросов:
Покажи все отправки по продукту ЕСЗК_Развитие сервиса
Покажи ответы по продукту Вклады за 2026 год
Покажи отправки по опросам без продукта

Под общим графиком доступны список опросов и графики по каждому опросу.
Режимы «Линии опросов» и «Доли опросов» раскрывают состав общего графика.
Нажмите на период для разбора вклада опросов в изменение. Сравнивайте
с предыдущим периодом или средним за три предыдущих наблюдаемых периода.
Пропуски не считаются нулями. Объёмы показывают источник изменения,
но сами по себе не доказывают сбой или разовый запуск.
Для экранов успеха отправки означают только записи со статусом SENDED.
