После аварийного закрытия блокировка снимается операционной системой.
Не закрывайте окно сервера, пока работаете с сайтом.

Основное хранилище — .local-data/analytics.sqlite3, с индексами по каналу,

Нельзя переносить только старый updates.json после работы в новой версии:

ОБНОВЛЕНИЕ ЭТОЙ И ПОСЛЕДУЮЩИХ ВЕРСИЙ
1. Скачайте новый ZIP проекта с GitHub.
2. Закройте окно сервера текущего проекта.
3. Запустите UPDATE_LOCAL.cmd в текущем проекте и укажите путь к ZIP.
4. После успешного обновления запустите START_LOCAL.cmd.

Перед заменой проверяется состав архива и SHA-256 каждого файла.
Обновление сохраняет папки date, .local-data и настройки CLI; создаёт копию
пользовательских файлов и прежних файлов приложения в .updates/backup-*.
При ошибке замены выполняется возврат файлов приложения из этой копии.
При работающем сервере обновление блокируется. Старые резервные копии
автоматически не удаляются. Обновляйте только своим доверенным архивом:
контрольная сумма проверяет целостность, а не автора архива.

ПЕРЕХОД С ПРЕЖНЕЙ ВЕРСИИ, ГДЕ НЕТ UPDATE_LOCAL.cmd
Закройте старый сервер. Распакуйте новый проект в новую папку. Скопируйте
в неё свои date и .local-data целиком, включая справочники и ai-config.json.
Запустите START_LOCAL.cmd. Старая папка остаётся резервной копией.

CLI
Совместимость проверяется по --help: --prompt и --approval-mode plan.
Номер версии сам по себе не гарантирует совместимость. Проверка --version
и --help не отправляет пользовательские данные модели и не подтверждает
авторизацию. Если CLI недоступна, локальный разбор остаётся доступным.

Быстрые кнопки добавления показателей сохраняют номер опроса, канал и период.
Уже добавленные показатели помечены на кнопках и не добавляются повторно.
Повторный текстовый запрос добавления сохраняет единственную пару «опрос + показатель».

Проценты количественных показателей: показатель / отправки того же опроса, канала и периода × 100. Значения выше 100% допустимы. При нулевой/неизвестной базе процент не показывается. CSI остаётся в баллах. Итог — отношение сумм, а не среднее процентов. CSV содержит отдельные колонки процента и базы.
Рейтинг: «Покажи 10 опросов с наибольшим количеством отправок за 2026 год» поддерживается наравне с «топ 10». Рейтинг не требует порогов аномалий.

2026.11.06.7 — недельный дашборд опроса 1007
На вкладке встречи добавлена «Динамика по общебанку».
По умолчанию: с 01.08.2026 по последнюю дневную дату в данных;
три кривые — события, отправки, ответы. Неделя: понедельник–воскресенье.
Первая и последняя недели обрезаются по датам фильтра.
«Другие показатели» включает стоп-листы, политику контактов, их сумму, CSI.

«Все доступные месяцы» расширяет период до первой дневной даты 2026 года.
Пустая дата окончания означает последнюю дату исходных дневных данных.
Другие графики не сбрасываются. Возврат на вкладку не запускает новый расчёт.
Есть CSV, PNG с настройками, разворачивание и добавление в презентацию.
Данные считаются по дневным строкам 1007; месячные строки не делятся
по неделям искусственно. При двух каналах нужно выбрать один.
Суммы и проценты рассчитаны по неделе; CSI взвешен по исходным events.
Недели без строк пропущены, известный ноль сохранён. Таблица показывает
точные границы недели и число дней со строками, не гарантию полноты данных.
Исходные CSV и база от настройки графика не меняются; вызов модели не нужен.

2026.11.06.8 — независимая правая шкала кривой в составных графиках
В «Отправки по событиям пуш+СМС» и «События по всем опросам пуш+СМС»
столбцы теперь относятся к ЛЕВОЙ оси, а кривая — к отдельной ПРАВОЙ оси.
По умолчанию и в режиме «Значения и проценты» слева доли 0–100%,
справа исходное количество отправок или событий. Поэтому столбец 100%
не читается как 120 млн по шкале кривой. Количество кривой не влияет
на масштаб столбцов. Оси и легенда явно подписаны.
Если сумма долей выше 100%, левая шкала расширяется до фактической суммы;
значения не нормируются и не обрезаются. Сверка status_det сохранена.
В режиме абсолютных значений у столбцов и кривой собственные шкалы количеств;
в режиме процентов — отдельные процентные шкалы. Выбранный режим сохранён.
Исправление действует на сайте, в увеличении, во всех PNG и в готовых
презентационных страницах/PPTX, включая ранее сохранённые JSON-снимки.
Сами числа и итоговые CSV не менялись. Остальные графики, в том числе
недельный общебанк 1007 с CSI, сохраняют свои прежние шкалы.

2026.11.10.1 — локальный контур мониторинга и отчётности
«Паспорт цифры» открывается по точке или из блока под графиком. Период, формула,
версия данных, доля и база передаются в лист «Паспорта» книги Excel и во
встроенную книгу диаграммы PowerPoint. На графиках встречи можно указать
автора ручных правок. Имена в локальном проекте вводятся участниками вручную.

«Утренний мониторинг» сравнивает две недели по сопоставимым дням.
Выберите сигнал, назначьте ответственного и срок. Для закрытия задачи
запишите результат проверки. Очередь и история сохраняются в SQLite.
Отсутствие строк статуса оставляет долю неизвестной. Отрицательный
арифметический остаток показывает перекрытие.

В «Рабочих сценариях» откройте успешно рассчитанный сценарий, затем
«Пакет на комитет». Черновик фиксирует данные последнего успешного запуска.
Автор отправляет его на согласование, другой участник утверждает или
возвращает с комментарием. Готовый ZIP содержит PPTX, Excel и манифест
с хэшем снимка, историей и сравнением с предыдущим утверждённым пакетом.
Согласование локальное. Для корпоративного пилота имена и полномочия
потребуется связать с банковской учётной записью.

Защищённый режим включён по умолчанию. CLI запускается с --approval-mode plan.
Для ИИ формируются ограниченные сводки и параметры. Стандартные расчёты,
мониторинг, задачи и отчёты работают без CLI. Генерация кода выключена,
доступен стандартный просмотр расчёта. Для экспериментов на тестовых данных
профиль development можно явно задать файлом .local-data/model-policy.json
с содержимым {"profile":"development"}. Файл настроек не включается в архив.
В диагностике есть эталонные проверки. Сборка запускает их автоматически.
Команда python release_eval.py --model проверяет настроенную CLI на двух
синтетических запросах и может расходовать квоту. Обычный запуск без
--model и кнопка в диагностике модель не вызывают.
2026.11.10.2

GigaCode показывает параметры графика перед расчётом. Можно исправить опросы,
канал, показатели и период. Сложный анализ позволяет проверить отбор перед
следующим вызовом модели. Пример: «Покажи опрос 1007 с августа 2026 по неделям».
Для недель нужны дневные наблюдения. Границы интервала могут дать неполные
недели; пропущенные наблюдения не заменяются нулём.

Кнопка «Разобрать сигнал» в утреннем мониторинге предлагает проверки по
локальным фактам. При явном выборе GigaCode упорядочивает эти проверки.
В модельном ответе можно собрать пакет на комитет и предложить черновик вывода.
После перезапуска согласование доступно в «Рабочие сценарии» → «Пакеты из диалога». Для недельного отчёта по 1007 при наличии данных включается
состав событий и отсечений. Экспорт утверждённого пакета содержит PPTX и Excel.
