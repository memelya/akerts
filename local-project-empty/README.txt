# Локальный дашборд — чистая версия

1. Распакуйте архив в НОВУЮ папку. Старую .local-data копировать не нужно.
2. Запустите START_LOCAL.cmd. Нужен Python 3.10 или новее. Node/npm не нужны.
   Альтернатива: python start_local.py. Откройте адрес из окна сервера.
3. Сохраните две выгрузки CSV в папке date с точными именами:
   push-sms.csv — пуш и СМС
   success-screen.csv — экраны успеха
4. Нажмите «Обновить данные» или F5. Сервер оставляйте работающим.

ПРИ ПЕРВОМ ЗАПУСКЕ НЕТ ДАННЫХ
Встроенных опросов, планов, справочников и исторических показателей нет.
CSV содержат только заголовки. baseline.json содержит пустые списки.
Опросы без справочника получают группу «без группы».

ПУШ И СМС — заголовки:
day_part;event_type_id;status_det;answer_csi;events;sends;answers

ЭКРАНЫ УСПЕХА — заголовки:
day_part;event_type_id;mp_status;answer_csi;sends;answers
Здесь sends — число записей в данном статусе/оценке; отправки экрана
считаются по SENDED. CSI взвешивается по числу записей с оценкой 1–5.

Дата: ДД.ММ.ГГГГ. Разделитель: точка с запятой, запятая или табуляция.
Кодировки: UTF-8 (рекомендуется), UTF-16, Windows-1251.
Пустую оценку оставляйте пустой, не удаляйте столбец.

ИСТОРИЯ ПОСЛЕ ПЕРВОЙ ЗАГРУЗКИ
Успешные загрузки сохраняются в .local-data/updates.json на этом ноутбуке.
Новые даты добавляются, совпадающие дата/опрос/статус/оценка заменяются
последней строкой. F5 не удваивает суммы. Очистка CSV не удаляет историю.
Ошибка CSV не заменяет последние корректные данные; сообщение укажет строку.
Для полного сброса: остановите сервер, удалите updates.json и его .bak,
очистите обе CSV до заголовков и снова запустите сервер.
Удалённый или пустой baseline.json допускается: база считается пустой.
Непустой повреждённый JSON требует исправления, чтобы не потерять данные.

Показатели считаются только из принятых файлов; пропуски не равны нулям.
Все файлы и расчёты локальные. Интернет для работы интерфейса не нужен.
Запускайте через START_LOCAL.cmd, не двойным щелчком по HTML.
