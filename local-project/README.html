Обновление локальных CSV

  1. Запустите START_LOCAL.cmd. Браузер откроется автоматически. Окно сервера оставьте открытым.
  2. Замените date/push-sms.csv и date/success-screen.csv своими выгрузками.
  3. Нажмите «Обновить данные» или F5. Файлы перечитываются без перезапуска сервера.

Используется установленный Python 3.10 или новее. Node.js, npm и интернет не нужны. Если запуск через CMD недоступен, откройте терминал в папке проекта:

python start_local.py

На macOS и Linux: python3 start_local.py. Команда python -m http.server показывает сохранённую копию, но не подключает CSV.

Пуш и СМС: дневные данные

day_part;event_type_id;status_det;answer_csi;events;sends;answers
29.10.2026;1007;0;5.0;10;10;10
29.10.2026;1007;0;;100;100;0
29.10.2026;1007;1011;;50;0;0

Экраны успеха: формат с вашего фото

day_part;event_type_id;mp_status;answer_csi;sends;answers
01.10.2026;155;SUCCEEDED;3.0;451;451
01.10.2026;942;SENDED;1.0;30;30
01.10.2026;1595;VIEW;;404;0

Здесь sends — количество записей каждого статуса и оценки. События — сумма этих количеств всех статусов. «Отправки · SENDED» — только статус SENDED. Ответы — сумма answers. CSI взвешивается по sends строк с оценками от 1 до 5. Пустые и нулевые оценки исключаются из CSI. Разные оценки не перезаписывают друг друга.

Экраны успеха: также поддерживается месячный формат

month;event_type_id;mp_status;cnt;qa_cnt;csi
2026-10;480;SENDED;100;5;4.5
2026-10;480;SUCCEEDED;20;20;4.8

Для дневных данных экранов успеха передайте day_part вместо month. Разделители: точка с запятой, запятая или табуляция. Поддерживаются UTF-8, UTF-16 и Windows-1251.

Замена и история

Совпадающий ключ заменяется последней строкой. Повторное обновление страницы не удваивает значения. Новые даты, месяцы и опросы добавляются автоматически. Для обнуления записи передайте тот же ключ и нулевые количества. Пропуск строки её не удаляет.

Принятые данные сохраняются в .local-data/updates.json. Прежние дни остаются после перезапуска. Для переноса на другой ноутбук скопируйте всю папку, включая .local-data.

Дневные данные заменяют месячный итог опроса, а не прибавляются к нему. При переходе между дневным и месячным форматом детализация за соответствующий месяц заменяется. Неполная выборка отмечается явно.

При ошибке CSV остаются последние корректные данные, а на странице показываются файл и строка ошибки. Исправьте файл и обновите страницу.

Всё работает на ноутбуке без отправки данных наружу. Подробности — в README.txt.
