ЛОКАЛЬНЫЙ ДАШБОРД С ОБНОВЛЕНИЕМ CSV

1. Распакуйте архив полностью в обычную папку на ноутбуке.
2. Дважды нажмите START_LOCAL.cmd. Используется уже установленный Python 3.10 или новее. Ничего из интернета не скачивается.
3. Браузер откроется по адресу из окна сервера, обычно http://127.0.0.1:8010/v2/ . Окно сервера оставьте открытым.
4. Положите выгрузку пуш/СМС в date/push-sms.csv, а экранов успеха в date/success-screen.csv. Замените файлы с этими именами, не добавляйте к ним расширение .txt.
5. Нажмите «Обновить данные» на странице или F5. Перезапускать сервер не нужно.

Альтернатива запуску CMD: откройте терминал в распакованной папке и выполните python start_local.py . На macOS/Linux: python3 start_local.py .
Команда python -m http.server показывает сохранённую копию сайта, но не подключает CSV. Для обновления нужен именно start_local.py.

ПУШ/СМС, ДНЕВНОЙ ФОРМАТ
day_part;event_type_id;status_det;answer_csi;events;sends;answers
29.10.2026;1007;0;5.0;10;10;10
29.10.2026;1007;0;;100;100;0
29.10.2026;1007;1011;;50;0;0

ЭКРАНЫ УСПЕХА, ДНЕВНОЙ ФОРМАТ С ВАШЕГО ФОТО
day_part;event_type_id;mp_status;answer_csi;sends;answers
01.10.2026;155;SUCCEEDED;3.0;451;451
01.10.2026;942;SENDED;1.0;30;30
01.10.2026;1595;VIEW;;404;0

В этой структуре sends — количество записей данного mp_status с данной оценкой. События на графике — сумма sends всех статусов; «Отправки · SENDED» — только записи статуса SENDED; ответы — сумма answers всех статусов. CSI = сумма(answer_csi × sends) / сумма(sends по строкам с оценками 1–5). Пустые и нулевые оценки не входят в CSI. Разные оценки одного ID/дня/статуса сохраняются раздельно.

ЭКРАНЫ УСПЕХА, ДОПОЛНИТЕЛЬНЫЙ МЕСЯЧНЫЙ ФОРМАТ
month;event_type_id;mp_status;cnt;qa_cnt;csi
2026-10;480;SENDED;100;5;4.5
2026-10;480;SUCCEEDED;20;20;4.8

Также поддерживается дневной агрегированный формат day_part;event_type_id;mp_status;cnt;qa_cnt;csi. Для дневных выгрузок доступны дни и недели. Разделители: точка с запятой, запятая, табуляция. Для дробей с запятой в CSV с разделителем запятая используйте кавычки, например "4,5". Кодировки: UTF-8, UTF-8 с BOM, UTF-16 и Windows-1251.

КАК ОБНОВЛЯЮТСЯ ДАННЫЕ
Повтор одной записи заменяется последней строкой. Дневной ключ пуш/СМС: дата + ID + статус + оценка. Ключ дневных экранов успеха с вашего фото: дата + ID + mp_status + answer_csi. Ключ агрегированных экранов успеха: дата/месяц + ID + mp_status. Отдельные оценки и статусы складываются только при расчёте итогов.
Новые даты, месяцы и опросы добавляются автоматически. ID вне справочника групп получает «без группы», вне справочника типов — «Триггерный (CSAT)».
Уже принятые CSV сохраняются в .local-data/updates.json. Поэтому можно последовательно подгружать отдельные новые дни: прежние дни сохранятся даже после перезапуска сервера или браузера. Для переноса на другой ноутбук скопируйте всю папку проекта, включая .local-data.
Чтобы исправить число, передайте тот же ключ с новым значением. Чтобы обнулить запись, передайте тот же ключ с нулевыми events/sends/answers (либо cnt/qa_cnt). Отсутствие строки не удаляет уже сохранённую запись. Удаление CSV тоже не сбрасывает историю.
Месячная выгрузка для того же опроса и месяца заменяет дневную детализацию за месяц. Дневная выгрузка заменяет прежний месячный итог: если старых дней нет в дневной истории, месяц явно помечается как неполная выборка. Дневные и месячные итоги не складываются между собой.
CSV с ошибкой не применяется целиком: остаются последние корректные данные, на странице видно имя файла и строку ошибки. Исправьте CSV и обновите страницу.

Данные читаются и хранятся на этом ноутбуке. Сервер слушает только 127.0.0.1. Сервисов, токенов, Node.js, npm и доступа к интернету не требуется.
Для остановки нажмите Ctrl+C в окне сервера. Копию всей папки можно использовать как резервную копию. Файл .local-data/updates.json.bak содержит предыдущую версию истории.
