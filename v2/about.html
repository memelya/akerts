Данные, расчёты и хранение

Периоды и ограничения

Источник — предоставленная агрегированная выборка. Дневная детализация текущего периода доступна для опросов 1007, 3155. Для остальных опросов доступны месячные итоги. Последний месяц может быть неполным. Дата публикации сайта не равна дате обновления исходной выборки.

0 означает переданное нулевое значение. «Нет данных» означает отсутствие наблюдения. «Неприменимо» означает, что показатель не относится к выбранному каналу: например, отправки пуш/SMS для экранов успеха.

Ответы и CSI — разные знаменатели

Ответы без оценки входят в количество ответов, но не входят в знаменатель CSI. Для дневной структуры CSI = Σ(answer_csi_sum) / Σ(events с оценкой 1–5). Для экранов успеха применяется исходная методика: Σ(cnt × csi) / Σ(cnt) по валидным оценкам. Эти методики не смешиваются.

Если источник передал только средний CSI, сумма оценок и число оценок не восстанавливаются искусственно. Нажмите показатель, чтобы увидеть доступную расшифровку.

План и прогноз

План за период = месячный план × прошедшие рабочие дни / рабочие дни месяца. В сохранённом расчёте рабочими считаются понедельник–пятница, без отдельного календаря праздников. Дата расчёта плана указана в расшифровке. Прогноз — сценарий сохранения среднего темпа, а не обещание результата.

Отсутствующие рабочие даты показываются разрывами. Недели ограничены месяцем и датой среза; количества суммируются, CSI пересчитывается с исходными весами.

Настройки и конфиденциальность

Избранное, сохранённые фильтры и плотность карточек хранятся только в этом браузере. Они не синхронизируются между устройствами и исчезают при очистке данных сайта. Настройки новой и основной версии разделены.

Отчёты CSV и HTML создаются в браузере и скачиваются на ваше устройство. Формы сайта не предназначены для ввода персональных банковских данных. Хостинг GitHub Pages обрабатывает обычные веб-запросы при открытии страниц.

Использование показателей

Дашборд предназначен для анализа предоставленной выборки. Рост количества событий по статусу отсечения сам по себе не доказывает ухудшение процесса: нужно учитывать общий объём и доли. До управленческого решения проверьте полноту данных и сопоставимость периодов.
